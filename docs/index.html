Essays on how models get served, how agents get built, and how anyone knows the output is right. Each one cites its sources, and the numbers come from the papers.

  2. 12Reward hacking is a bug report about your tests

    An agent that games your tests is exposing a hole in your verifier, so fix the checker before blaming the model.

  3. 11Build the benchmark you will be judged by

  4. 10Test-time compute is capped by its verifier
